## Contents

- Responsive layout and Print / Save PDF option

## Update the website

Edit `index.html` for profile text, `style.css` for styling and `app.js` for the print action.
GitHub Pages serves the site from the root of `main`. No build step or API key is required.

## Local preview

Run `python3 -m http.server 8000` in this directory and open http://localhost:8000/.
